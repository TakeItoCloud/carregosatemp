**Phase A.2 — NEW pre-flight: catch the Tiago/Diana problems before starting (on-prem EMS):**
```powershell
$Users | ForEach-Object {
  $fs  = Get-MailboxFolderStatistics $_
  $fsA = Get-MailboxFolderStatistics $_ -Archive -ErrorAction SilentlyContinue
  $big = ($fs + $fsA | Sort-Object ItemsInFolder -Descending | Select-Object -First 1)
  [pscustomobject]@{
    User=$_; PrimaryFolders=$fs.Count; ArchiveFolders=($fsA|Measure-Object).Count
    BiggestFolderItems=$big.ItemsInFolder; BiggestFolderPath=$big.FolderPath
  }
} | Tee-Object -Variable pf | Format-Table -Auto
$pf | Export-Csv "$OutDir\preflight-folders.csv" -NoTypeInformation
```
**Act on this before you migrate:** any mailbox with **>1,000 folders** (Tiago's failure) or a **single folder >~100k items** (Diana's) gets `ExtendedEwsTimeout=1` on its MigrationWiz item up front, and for the oversized folder, agree a split with the client — don't start it blind like we did.

**Phase E — Verify cloud mailbox + archive + auto-expand (Exchange Online):**
```powershell
Connect-ExchangeOnline
$Cloud = $Users | ForEach-Object { ($_ -split '@')[0] + '@bancocarregosa.com' }   # JesseAkers already correct
$Cloud | ForEach-Object {
  Get-EXOMailbox $_ -Properties ExchangeGuid,ArchiveGuid,ArchiveStatus,AutoExpandingArchiveEnabled `
```

**Phase G — Run the passes:**
- Select the new users → **Start → Pre-Stage Migration** (email only) now.
- Keep concurrency sane and **don't run a mailbox flagged in Phase A.2 at full tilt** until its timeout/folder mitigation is in place.
- The **Full** pass is the cutover-day delta (calendar/contacts/rules + recent mail).

**Phase H — Cutover (later, per user — the delicate part):**
Capture the GUIDs **before** disabling (Disable-Mailbox wipes the CustomAttributes), then:
